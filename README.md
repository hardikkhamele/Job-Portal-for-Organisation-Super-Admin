# Job Portal for Organisation Super Admin

A comprehensive, enterprise-ready **Job Portal Super Admin Panel** designed for organizations of all sizes (small, medium, and large) to streamline candidate hiring, recruiter operations, and sales execution workflows in a centralized hub.

---

## 🎯 Aim & Purpose

The primary aim of this project is to eliminate fragmented hiring workflows by providing a **centralized Super Admin Management System**. It empowers organizations to oversee end-to-end recruitment pipelines, manage internal team roles (HR Recruiters, Sales Executives, Super Admins), track company vacancy postings, and monitor hiring metrics efficiently.

---

## 🛑 The Problem

Modern small-to-medium enterprises (SMEs) and growing organizations face several critical challenges in recruitment and workforce acquisition:
1. **Uncoordinated Hiring Channels**: Difficulty tracking candidate status across multiple recruiters and external clients/departments.
2. **Role Ambiguity & Poor Tracking**: Lack of centralized oversight for HR Recruiters managing open roles versus Sales Executives managing client company requirements.
3. **Inefficient Vacancy Management**: Manual or scattered data entry leading to errors in state/city requirements, salary ranges, candidate stage tracking, and client billing/commissions.
4. **Lack of Real-time Visibility**: Absence of dashboard analytics to evaluate HR recruiter output, vacancy fulfillment speed, and active sales pipelines.

---

## 💡 The Solution

The **Job Portal Super Admin** system provides a robust, intuitive React-based administration dashboard that unifies company onboarding, job vacancy allocation, candidate tracking, and team management:
- **Centralized Administration**: High-level super admin oversight over all organizations, client profiles, and internal users.
- **Role-Based Workflow Synchronization**: Connects **Sales Executives** (who manage client company demands) seamlessly with **HR Recruiters** (who handle candidate sourcing and interviews).
- **Structured Candidate Pipeline**: Complete visibility into candidate profiles, interview schedules, status updates (Screening, Interviewing, Offered, Placed), and status tracking.
- **Dynamic Search & Filtering**: Location-aware vacancy search (State & City dropdowns), real-time filtering, and custom table views.

---

## ✨ Key Features

### 🏢 1. Company & Requirement Management
- **Organization Onboarding**: Add and manage client companies, company profiles, contact details, and location details.
- **Job Vacancy Creation**: Streamlined multi-step form to create vacancies with customizable designations, skill tags, salary bands, and experience criteria.
- **State & City Filtering**: Searchable dropdowns for dynamic location-based job requirement tagging.

### 👥 2. Candidate & Sourcing Hub
- **Detailed Candidate Profiles**: Maintain candidate contact details, current status, applied role, and resume links.
- **Vacancy Alignment**: Direct mapping between candidates and active job openings for rapid shortlisting.
- **Candidate Status Tracker**: Track candidates across stages (Sourced, Shortlisted, Interview Scheduled, Selected, Rejected).

### 👔 3. HR Recruiter Management
- **HR Dashboard & Performance Tracking**: Monitor recruiter activity, assigned vacancies, candidate pipeline health, and successful placements.
- **Recruiter Workloads**: Assign and reassign job requisitions to individual recruiters or HR teams.

### 💼 4. Sales Executive Module
- **Client & Lead Management**: Allow Sales Executives to onboard new corporate client accounts and job requisitions.
- **Requisition Pipeline**: Bridge sales contracts directly into actionable vacancies for HR recruiters.

### 🔐 5. Super Admin Dashboard & Controls
- **Analytics & Insights**: Overview cards for total vacancies, pending approvals, active HR recruiters, and candidate conversions.
- **Clean UI & Responsive Experience**: Modern styling, seamless modal navigation, breadcrumbs, and zero-clutter data tables.

## 🛠️ Tech Stack

- **Frontend**: React.js, Vite
- **UI & Iconography**: Lucide React / React Icons, Custom Modular CSS, Responsive Layouts
- **State & Router**: React Router DOM
- **HTTP Client**: Axios / Fetch API

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v16.x or higher recommended).

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/hardikkhamele/Job-Portal-for-Organisation-Super-Admin.git
   ```

2. **Navigate into the directory**:
   ```bash
   cd Job-Portal-for-Organisation-Super-Admin
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Open in browser**:
   Visit `http://localhost:5173` (or the port specified in terminal).
